# Project Name

**Scheels.com Project**

## Description

"A tiny web app that prints the numbers from a configurable range, replacing multiples of 3 with **SCHEELS**, multiples of 5 with **.COM**, and multiples of both with **SCHEELS.COM**."

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/LanceBalstad/ScheelsProject.git

   ```

2. Running the Application
   Double-click index.html in your file explorer to open it in a browser of your choice.
